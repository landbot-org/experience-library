# Inbound lead qualifier call

Qualifies a new lead in two minutes, then books a demo or points small teams to the free trial.

| | |
|---|---|
| Use case | Sales |
| Channel | Voice agent (ElevenLabs) |
| Runs as | **Quillbeam** (invented) |
| Language | English |
| Try it | [Talk to it live](https://experiences.getagent.page/voice/lead-qualifier) |

## Rebuilding it

Not possible from this repo. Voice agents run on ElevenLabs, not Landbot,
and their configuration is not exported here. Calls end after four minutes;
the card beside the call shows what would land in the Landbot inbox.
