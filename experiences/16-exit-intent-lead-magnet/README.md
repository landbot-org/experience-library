# Exit-intent lead magnet

A bottom sheet that offers a report before the visitor leaves.

| | |
|---|---|
| Use case | Lead capture |
| Channel | Landbot web chat |
| Runs as | **Quillmarsh** (invented) |
| Language | English |
| Try it | [Try it live](https://landbot.pro/v3/H-3517953-6FMKHVMZGWEK2LS8/index.html) |

<img src="preview.jpg" alt="Exit-intent lead magnet, screenshot of the live experience" width="300">

## How it opens

> Leaving already? Take the 2026 pricing benchmark. Pricing models and price points by market, in one short report. Three quick questions and it's in your inbox.

with the Custom Code feature, so a rebuild on an account without it will
not look like the preview.
