# Holiday-rental guest line

Guests call about parking or a problem; it answers from approved info and hands over when they are stuck.

| | |
|---|---|
| Use case | Support |
| Channel | Voice agent (ElevenLabs) |
| Runs as | **Costaluma Stays** (invented) |
| Language | English, Spanish |
| Try it | [Talk to it live](https://experiences.getagent.page/voice/guest-line) |

## Rebuilding it

Not possible from this repo. Voice agents run on ElevenLabs, not Landbot,
and their configuration is not exported here. Calls end after four minutes;
the card beside the call shows what would land in the Landbot inbox.
