## Using it with Claude

Point Claude at this repo. [`AGENTS.md`](AGENTS.md) tells it what is here and
how to recommend, explain or rebuild an experience.

## Rebuilding an experience in your own Landbot account

You need your own Landbot account with the Bots API enabled, and the Landbot
plugin for Claude. Experiences can be rebuilt only once their export is in this
repo: see the `export` flags in [`catalog.json`](catalog.json).
